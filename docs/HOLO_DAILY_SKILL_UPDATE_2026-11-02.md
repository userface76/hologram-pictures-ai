## 스킬 1 — Performance-to-Character Geometry Gate
**한국어:** 동작 참조 영상과 캐릭터 신체 비율·방향 호환성 검사

### 핵심 원리
동작 참조 영상으로 캐릭터를 움직이는 경우, 원본 퍼포먼스 영상과 대상 캐릭터 이미지의 **신체 비율, 보이는 신체 범위, 자세/방향, 가림 여부**가 호환되어야 한다. Runway에서 제공하는 Kling 3.0 Motion Control 공식 가이드는 전신 동작에는 머리와 사지가 명확히 보이는 단일 인물 퍼포먼스 영상, 컷/과도한 카메라 움직임이 없는 연속 샷, 비교적 안정적인 동작, 비슷한 비율의 캐릭터 이미지를 권장한다. 인물의 방향은 Image 또는 Video 기준을 선택할 수 있다.

### 적용 조건
- 인물·캐릭터/애니·판타지/패션·뷰티에서 춤·손동작·표정·전신 동작을 특정 캐릭터로 옮길 때.
- 광고·브랜드/숏폼/시네마틱에서 동일 캐릭터의 동작 재현성이 중요할 때.
- **Kling 3.0 Motion Control 또는 동등한 기능을 실제로 제공하는 엔진에만 적용.** HOLO의 MiniMax H3에 이 API 옵션이 존재한다고 가정하지 않는다.

### 좋은 예시
전신이 나오는 6초 연속 영상에서 모델이 천천히 손을 들어 제품을 소개한다. 캐릭터 레퍼런스도 머리·팔·다리가 모두 보이는 전신 이미지이며 신체 비율이 비슷하다. 먼저 이미지/영상 방향 설정을 각각 시험하고, 얼굴·손·제품 위치가 유지되는 쪽을 선택한다. 원본 영상의 오디오를 사용하지 않을 때는 Original Sound를 끈다.

### 피해야 할 경우
- 상반신 캐릭터 사진으로 전신 점프/걷기 동작을 전이.
- 인물 여러 명, 빠른 컷 전환, 강한 카메라 흔들림, 사지 가림이 많은 동작 참조.
- 정면 캐릭터와 측면 퍼포먼스의 방향 차이를 확인하지 않고 일괄 생성.
- 동작 전이 기능을 한국어 음성 안정화 기능으로 오인.
- 퍼포먼스 원본에 대한 사용권/초상권을 확인하지 않음.

### 공급자별 조건 및 검증
Runway의 Kling 3.0 Motion Control 안내 기준: 영상 방향 모드 최대 30초, 이미지 방향 모드 최대 10초, 3초 이상, 16:9/9:16/1:1, 720p/1080p. 이는 해당 공급자 UI 기준이며 HOLO MiniMax 설정에 직접 복사하지 않는다.
QA: 캐릭터 정체성, 신체 비율, 손/발 개수·관절, 동작 타이밍, 방향, 화면 밖 이탈, 제품 소품 보존, 원본 오디오 사용 여부. A/B는 동일 입력에서 방향 선택만 변경하고 비교한다.

### 기존 스킬과 차이
기존 Motion Cue Conflict Check는 **정지 이미지에 암시된 움직임 vs 텍스트 모션 지시**의 충돌을 검사한다. 이 스킬은 **퍼포먼스 비디오와 캐릭터 이미지 간 기하학적 호환성**을 검사한다.

## 스킬 2 — Multi-Shot Intent & Identity Anchor Plan
**한국어:** 단일 생성 내 다중 샷 목적·정체성 앵커 설계

### 핵심 원리
하나의 영상에서 여러 카메라 컷이 필요할 때 각 샷의 **서사 역할, 카메라 거리/방향, 인물·제품 고정 요소, 전환 목적**을 먼저 지정한다. Runway Multi-Shot Video 공식 문서는 하나의 프롬프트에서 최대 5개 연결 샷을 생성하고, Auto 모드 또는 샷별 지시를 직접 쓰는 Custom 모드를 제공한다고 설명한다. 시작 이미지를 선택적으로 사용해 첫 샷의 외관을 고정할 수 있다.

### 적용 조건
- 10~15초 브랜드 광고에서 훅→제품 공개→사용 장면→엔딩 등 여러 샷이 필요할 때.
- 시네마틱, 숏폼, 패션/뷰티, 제품·푸드 등 컷의 의미가 중요한 경우.
- Runway의 Multi-Shot Video 앱(Kling Pro 3.0 기반) 또는 실제로 다중 샷 입력을 지원하는 엔진에만 직접 적용한다. HOLO MiniMax H3에 동일 기능이 있다는 뜻은 아니다.
- **대사가 많은 영상은 샷을 늘리기보다 음성 길이 게이트로 먼저 검사**한다.

### 좋은 예시
12초 세럼 광고의 샷 계획: (1) 0~3초 브랜드 병의 정면 클로즈업과 느린 돌리인, (2) 3~6초 동일 병을 손에 드는 미디엄 샷, (3) 6~9초 같은 모델이 제품을 사용하는 측면 샷, (4) 9~12초 동일 병과 승인된 로고 그래픽의 엔드 카드. 모든 샷에서 동일 SKU·패키지 색·모델 의상·주광 방향을 고정한다. 시간 표기는 **제작 의도**이며 모델이 정확한 초 단위 컷을 보장한다는 뜻은 아니다.

### 피해야 할 경우
- 하나의 8~10초 클립에 5개 이상의 복잡한 행동/대사를 강제.
- 각 샷마다 다른 제품 사진·패키지 버전·모델 의상을 사용.
- 시작 이미지 한 장만으로 이후 모든 컷의 제품/얼굴 일관성이 보장된다고 단정.
- 여러 샷을 합성하는 것과 기존 Last-Frame Bridge(별도 클립 간 연결)를 혼동.
- 공급자 앱의 다중 샷 옵션을 MiniMax 직접 API에 임의 전송.

### 검증
샷별 역할이 명확한 Custom 계획과 자유로운 Auto 계획을 같은 주제·길이·입력으로 비교한다. 컷 수, 서사 전달력, 동일 제품/얼굴 유지, 라벨 가독성, 카메라 방향, 생성비용, 재생성률을 기록한다. 로고 텍스트는 기존 Tracked Brand Graphic 워크플로를 유지한다.

### 기존 스킬과 차이
Last-Frame Bridge with Seam QA는 **이미 생성한 별도 클립 사이**의 연속성을 다룬다. 이 스킬은 **한 번의 다중 샷 생성 요청 이전**에 샷별 목적과 고정 요소를 설계한다.
