## 1. Motion Cue Conflict Check (움직임 단서 충돌 검사)
**근거:** Runway Image to Video Prompting Guide 및 Gen-4 Prompting Guide. 이미지의 모션블러, 먼지, 달리는 자세, 방향선 등은 모델에 움직임을 암시하며, 정지·역방향 이동 같은 프롬프트와 충돌할 수 있다.

- **원리:** 생성 전 원본 이미지의 암시적 움직임과 요청한 피사체/카메라 움직임이 일치하는지 확인한다.
- **적용 조건:** 사진 한 장 기반 영상, 제품 고정 샷, 패션 포즈, 정지 차량을 돌며 촬영하는 시네마틱, 캐릭터의 방향 전환.
- **좋은 예시:** 자동차 사진에 먼지와 모션블러가 있으면 정지 차량의 오비트 카메라 샷을 생성하기 전에 먼지·블러를 제거한 입력 이미지를 사용한다. 이후 카메라만 수평 아크로 이동하도록 지시한다.
- **피해야 할 경우:** 의도적으로 운동감을 보존해야 하는 추격 장면에서 모든 모션블러를 없애는 것. 프롬프트만 길게 반복해 충돌을 덮으려는 것.
- **QA:** 이미지의 암시적 이동 방향, 요청된 피사체 동작, 카메라 동작, 시간 순서 사이 충돌 체크; 수정 전후 같은 조건으로 비교.
- **카테고리:** 시네마틱/제품·푸드/패션·뷰티 우선, 광고·브랜드/숏폼/인물·캐릭터/애니·판타지 적용, 아트·실험 선택.
- **기존 스킬과 구분:** 레퍼런스 역할·품질을 정하는 스킬이 아니라, **입력 이미지의 암시적 운동 정보와 요청 모션의 충돌**을 검사한다.
- **출처:** https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide ; https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide

## 2. Korean Dialogue Duration Gate (한국어 대사 길이 검사)
**근거 수준:** HOLO 사용자 보고 기반 운영 가설. MiniMax 한국어 음성 품질/속도 문제의 원인이 검증되었다는 뜻은 아님.

- **원리:** 영상 클립 길이와 발화 길이를 사전에 비교한다. 대사 원문·언어 코드·요청 길이·원본 오디오 길이·최종 오디오 길이를 로그로 남겨 생성 엔진 문제와 합성 속도 변경 문제를 구분한다.
- **적용 조건:** 한국어 대사가 있는 광고·브랜드, 숏폼, 인물·캐릭터, 제품·푸드, 패션·뷰티.
- **좋은 예시:** 10초 장면에 긴 한국어 문장이 들어오면 무조건 속도를 올리는 대신 사용자에게 대사 축약/장면 분할을 제안한다. 생성 뒤 실제 한국어 여부와 발화 속도를 검수하고, 중국어 혼입이나 과속이면 해당 구간을 재생성한다.
- **피해야 할 경우:** 고정 음절/초 값을 모든 화자·모델에 적용하는 것, 음성 분석 없이 중국어라고 확정하는 것, 영상 길이를 맞추기 위해 오디오 재생속도를 무단 변경하는 것.
- **QA:** 음절 수 및 예상 발화 시간(보수적 범위), 무음/쉼, ASR 언어 감지 신뢰도, 실제 음성 길이, 합성 시 time-stretch 적용 여부, 구간별 재생성 성공률. 자동 언어 감지 결과는 사람 검수로 확인.
- **카테고리:** 광고·브랜드/숏폼/인물·캐릭터 우선, 제품·푸드/패션·뷰티 조건부, 시네마틱/애니·판타지 대사 포함 시 적용, 아트·실험 선택.
- **기존 스킬과 구분:** 영상 모션/레퍼런스 규칙과 별개로, 대사·음성·합성 파이프라인의 길이와 언어를 검증하는 게이트.
- **검증 계획:** 동일 대사 3종(짧음/중간/긴 문장)을 동일 모델·동일 길이에서 반복 테스트; 원본 오디오와 최종 MP4 비교. 아직 HOLO 엔진 코드에 적용하지 않음.

## 변경 전후
- 이전: 이미지·대사 입력 → 프롬프트 → 생성 → 최종 육안 검수.
- 이후: 이미지 운동 단서 충돌 검사 + 한국어 대사 길이/언어 계획 → 기존 레퍼런스·연출 스킬 적용 → 생성 → 모션/음성/언어 검수.

## 배포 상태
문서만 추가. HOLO 런타임 코드·자동 QA·배포 변경 없음. 공식 자료에서 지원하는 사항과 HOLO 자체 실험 가설을 구분함.

### 3. MiniMax Korean Speech Locale & Pause Contract — 한국어 음성 언어·쉼 제어
- **핵심 원리:** MiniMax T2A HTTP 공식 API는 \`language_boost\`에 \`Korean\`을 지원하고 \`voice_setting.speed\`를 제공한다. 또한 텍스트 중간에 \`<#0.4#>\`와 같은 쉼 마커를 넣을 수 있고, \`subtitle_enable\` 및 \`subtitle_type\`으로 문장/단어 수준 타임스탬프를 받을 수 있다. 이는 10/30 기존 'Korean Dialogue Duration Gate'의 **실행 가능한 API 입력·출력 제어 계층**이다.
- **적용 조건:** HOLO가 MiniMax **별도 TTS API**를 사용하는 경우. 영상 모델 H3의 내장 음성 생성에는 동일한 필드가 있다는 근거가 없으므로 그대로 전송하지 않는다.
- **좋은 예시:** 10초 광고용 대사를 미리 2문장으로 줄인 뒤, 지원되는 TTS 요청에 \`language_boost:"Korean"\`, \`voice_setting.speed:1\`, 필요할 때 문장 사이 \`<#0.3#>\`을 설정한다. 응답의 실제 오디오 길이와 문장/단어 타임스탬프를 읽어 HOLO Composer에서 음성을 임의 가속하지 않고 컷 길이를 조절한다.
- **피해야 할 경우:** \`language_boost\`만으로 중국어 혼입이 완전히 해결된다고 보장하는 것, H3 영상 생성 API에 TTS 전용 필드를 넣는 것, 쉼 마커를 발화 중간에 남발하는 것, 속도를 자동으로 과도하게 높여 분량을 맞추는 것.
- **검증:** 동일한 한국어 3개 대사(짧음/중간/긴 문장)에 대해 auto vs Korean 비교; 원본 TTS와 최종 MP4의 발화 속도·언어·오디오 길이·타임스탬프 차이 기록. 음성 언어 인식 결과는 사람 검수.
- **카테고리:** 광고·브랜드, 숏폼, 인물·캐릭터 = 우선; 제품·푸드, 패션·뷰티 = 내레이션 시; 시네마틱, 애니·판타지 = 대사 시; 아트·실험 = 선택.
- **공식 출처 (2026-10-30 확인):** https://platform.minimax.io/docs/api-reference/speech-t2a-http (language_boost Korean, voice speed, pause marker, subtitle timestamps)
- **상태:** 문서 규칙만 추가; HOLO 실제 TTS 호출 경로 및 H3 지원 여부는 코드/런타임 검증 필요.

### 4. Last-Frame Bridge with Seam QA — 마지막 프레임 연결·이음새 검수
- **핵심 원리:** 짧은 AI 영상 여러 개를 긴 영상으로 연결할 때 첫 클립의 마지막 프레임을 다음 클립의 시작 이미지로 재사용한다. Runway 공식 가이드는 마지막 프레임 재활용과 편집기에서 중복 프레임 제거를 안내한다. Luma Ray-2 API도 시작·종료 키프레임을 명시하는 기능을 문서화한다.
- **적용 조건:** 동일 인물/제품/배경이 이어지는 10~30초 이상의 시퀀스, 스토리 숏폼, 제품 카메라 워크. **엔진이 시작 프레임 또는 키프레임 입력을 지원할 때만** 직접 적용.
- **좋은 예시:** 10초 화장품 클로즈업의 마지막 프레임을 다음 10초 영상의 첫 프레임으로 전달하고, 다음 프롬프트에는 인물 손동작·카메라 방향만 명확히 지시한다. 편집 시 공유 프레임 1개를 제거하고 노출·화이트밸런스·제품 위치·카메라 진행 방향을 점검한다.
- **피해야 할 경우:** 1편 마지막 프레임 자체에 손/얼굴/로고 왜곡이 있을 때 그대로 전파하는 것, 서로 다른 제품 버전·배경으로 바꾸는 장면을 무리하게 연결하는 것, 프레임 공유만으로 음성·동작 연속성이 보장된다고 가정하는 것.
- **검증:** 클립 A 마지막 프레임과 클립 B 첫 프레임의 구도/주체/제품 라벨 일치, 편집 후 중복 프레임/끊김, 움직임 방향, 음성 크로스페이드 확인. 불일치 시 A의 끝 프레임을 교정하거나 B를 부분 재생성.
- **카테고리:** 시네마틱, 숏폼, 광고·브랜드, 인물·캐릭터, 애니·판타지 = 우선; 제품·푸드, 패션·뷰티 = 동일 제품/인물 연속 컷; 아트·실험 = 선택.
- **공식 출처 (2026-10-30 확인):** https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide ; https://help.runwayml.com/hc/en-us/articles/41748090660499-Creating-Multi-Character-Dialogues-with-Act-Two ; https://docs.lumalabs.ai/docs/video-generation
- **상태:** 문서 규칙만 추가; HOLO MiniMax H3 어댑터가 해당 프레임 입력을 지원하는지는 확인 전.
