## 신규 스킬 — Layer-Separated Motion Planning & Occlusion QA
- **핵심 원리:** 승인된 한 장의 이미지에서 배경·인물·제품·전경 장식 등 독립 레이어를 추출해, 각 요소에 서로 다른 이동량/깊이/패럴랙스 계획을 부여한다. Runway Dev는 2026-11-10 Seedream 5 Pro Layers 이미지 분해 기능을 공개했다. 결과는 기본 이미지와 투명 PNG 레이어 및 가능한 경우 레이어 이름·순서·경계를 포함한다. 2026-11-11 과금은 분해당 고정액에서 반환 이미지 수 기준으로 변경되었다.
- **적용 조건:** 승인된 정지 이미지가 있고, 영상 생성 전 피사체와 배경의 움직임을 분리할 가치가 있을 때. 레이어 분해는 영상 모션을 자동 보장하지 않으며, 실제 모션 적용은 별도 합성/영상 엔진 작업이다.
- **좋은 예:** 15초 향수 광고의 승인된 제품 정지 이미지에서 병/전경 꽃잎/배경을 분리해 배경은 느리게, 꽃잎은 조금 빠르게 이동시키되 병의 로고와 윤곽은 정지 유지. 시차 효과는 합성 후 검수.
- **피해야 할 경우:** 투명 경계에 머리카락·유리·반사광이 섞인 경우, 제품 라벨이나 얼굴이 레이어 분해 중 변형된 경우, 원본 라이선스가 불명확한 경우, 단순 카메라 줌으로 충분한 장면.
- **QA 필드:** approved_source_asset_id, layer_asset_ids, layer_order, alpha_edge_review, occlusion_order, protected_regions, label_legibility, face_identity_review, composite_preview_approval, provider_support.
- **기존 스킬과 차이:** 첫 프레임 승인은 '전체 정지 이미지 검수', 제품 교체는 '영상 내 물체 대체', 이번 스킬은 '정지 이미지의 전경/중경/배경 분해 및 가림 순서 관리'다.
- **근거:** Runway Dev API Changelog (2026-11-10, 2026-11-11), https://docs.dev.runwayml.com/api-details/api_changelog/ (2026-11-13 확인). 해당 API의 비용은 반환 이미지 수와 해상도에 따라 달라지므로 최신 가격표를 다시 확인할 것.
