# HOLO AI Daily Skill Update — 2026-11-23 (KST)

## 검토와 채택
광고·브랜드 / 시네마틱 / 숏폼 / 제품·푸드 / 인물·캐릭터 / 애니·판타지 / 패션·뷰티 / 아트·실험 8개 범주를 검토했다. 기존 11월 13~22일의 레이어, UGC, 동작 전이, 컷 예산, 프롬프트 확장, HDR, 3앵커, 모델 라우팅, 입력 크롭, 초안 승격 스킬과 비교했다. 새로 채택한 스킬은 **1개**. 기존 기능의 중복 추가가 아닌, 다중 참조 입력 간 **허용 조합과 역할 충돌을 생성 전 차단**하는 운영 규칙이다.

## 신규 스킬: Multi-Modal Reference Role & Compatibility Gate
- **원리:** 참조별 역할을 명시한다. 인물/제품 이미지=외형, 영상=카메라·동작, 오디오=리듬/페이싱. MiniMax H3의 Runway UI 문서에는 이미지 참조 최대 9개, 영상 최대 3개, 오디오 최대 3개, 5~15초, 768p/2K, 여러 화면비 지원이 명시되어 있다. 그러나 **키프레임과 참조 입력을 동시에 결합할 수 없다**. 모델/제공자/해상도에 따라 조합 제한이 추가로 존재할 수 있다.
- **사전 검사:** (1) 제작 목적별 필수 참조와 역할 지정 (2) keyframe 경로 또는 reference 경로 중 하나만 선택 (3) 지원 입력 개수·길이·해상도·화면비 확인 (4) 얼굴/제품/로고 승인본 해시·버전 기록 (5) 동작·음성·제품 간 상충 지시 제거 (6) 실패 시 자동 생성하지 말고 입력 수정 안내.
- **좋은 예:** 9:16, 10초 화장품 UGC에서 승인된 모델 사진(인물 외형), 세럼 병 사진(제품 외형), 손동작 참조 영상(움직임), 짧은 리듬 참조 오디오(페이싱)를 각각 역할 지정한다. 참조 기반 모드로 구성하고 별도의 시작·종료 키프레임은 섞지 않는다. 생성 후 얼굴·라벨·손 접촉·한국어 발음을 검수한다.
- **피해야 할 경우:** 키프레임과 참조 입력을 동시에 강제로 전송, 서로 다른 모델 얼굴 사진 혼용, 제품 라벨이 상충하는 이미지 혼용, 오디오 참조가 한국어 발화 정확도를 보장한다고 주장, Runway UI 명세를 HOLO MiniMax 직접 API의 검증된 계약으로 간주.
- **적용 조건:** Runway에서 확인된 MiniMax H3의 사용자 인터페이스 명세를 기준으로 한 **설계 규칙**. HOLO의 직접 MiniMax API 파라미터·허용 조합은 실제 스키마 확인 전까지 미확인. 코드나 엔진에는 적용하지 않았다.
- **권장 필드(미구현):** provider, model, generation_mode, keyframes[], image_refs[{role,asset_version}], video_refs[{role}], audio_refs[{role}], compatibility_checked, identity_QA, product_QA, Korean_speech_QA.
- **기존 기술과 차이:** 11/15는 동작 전이의 신체 비례, 11/19는 3개 시간 앵커, 11/20은 모델 선택, 11/21은 크롭 안전성이다. 이번 기술은 **여러 입력 매체의 역할·조합 적합성**을 검사한다.

## 8개 카테고리별 적용
| 카테고리 | 적용 |
|---|---|
| 광고·브랜드 | 로고/제품 이미지와 동작 참조 역할 분리 (우선) |
| 시네마틱 | 카메라 이동 참조 영상과 피사체 외형 참조 구분 |
| 숏폼 | 리듬 오디오와 장면/인물 참조의 충돌 예방 |
| 제품·푸드 | 제품 외형/손 사용 동작 분리 (우선) |
| 인물·캐릭터 | 얼굴 고정 참조와 움직임 참조 분리 (우선) |
| 애니·판타지 | 캐릭터 디자인과 변신 동작의 역할 구분 |
| 패션·뷰티 | 모델/의상 이미지와 워킹 영상 분리 (우선) |
| 아트·실험 | 참조 종류별 효과를 통제된 조건에서 비교 |

## 변경 전후
- **전:** 승인 참조 → 프롬프트/모델 선택 → 생성 → 결과 QA.
- **후(문서상 제안):** 승인 참조 → 매체별 역할 지정 → 키프레임/다중 참조 모드 배타성·지원 개수 확인 → 충돌 검사 → 생성 → 기존 QA.
- **변경 범위:** 이 문서만 추가. HOLO API/WEB, MiniMax 직접 연동, Railway, 영상 테스트 변경 없음. 성능 개선은 실측 전.
