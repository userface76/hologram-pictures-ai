## 신규 채택: Product Reference Acquisition Gate (제품 원본 레퍼런스 입력 품질 게이트)

### 핵심 원리
제품의 외형을 잘 유지하려면 생성 후 보정 이전에 **제품 참조 이미지 자체의 품질**을 통제해야 한다. 고해상도, 명확한 단일 피사체, 가림 없는 제품, 원하는 촬영 각도, 중립적 조명과 깨끗한 배경을 우선한다. 여러 각도가 필요한 경우 같은 실물·같은 패키지 버전의 이미지만 모은다. 첫 이미지가 대표 이미지로 쓰이는 모델/워크플로에서는 승인된 대표 컷을 첫 번째로 둔다.

### 기존 스킬과 차이
Reference Role Separation/Responsibility Map은 레퍼런스의 역할과 속성 소유권을, Reference Budget Router는 입력 개수와 중복을 관리한다. 오늘 스킬은 **제품 레퍼런스 촬영·선정 단계의 입력 품질 합격 기준**이다. 10월 16일 Tracked Brand Graphic은 생성 후 정확한 문구의 합성을 다룬다.

### 적용 조건
- 실제 제품과 동일한 색·형태·뚜껑·라벨·포장 버전을 유지해야 하는 광고, 제품 시연, 음식/뷰티 영상
- 제품 이미지 여러 장을 사용하거나 제품 교체(Product Swap) 워크플로를 사용할 때
- 얼굴·패션 아이템도 단일 대상의 명확한 원본을 준비할 때 확장 가능

### 좋은 예시
음료 광고: 승인된 최신 패키지의 정면 제품 사진을 첫 참조로, 같은 패키지의 45도 및 측면 컷을 보조로 제공한다. 과도한 반사·워터마크·손 가림을 제거한 소스만 사용한다. 카메라 동작과 장면 무드는 별도 지시하고, 최종 로고 철자는 기존 Tracked Brand Graphic 규칙으로 검수한다.

### 피해야 할 경우
- 서로 다른 리뉴얼 버전의 패키지 이미지 혼용
- 로고가 가려진 저해상도 SNS 캡처를 유일한 참조로 사용
- 반사/투명 소재의 정체성을 단일 정면 사진만으로 충분히 추정했다고 간주
- 여러 인물·제품이 뒤섞인 사진을 단일 제품 참조로 사용
- 모델별 입력 제한 및 참조 이미지 순서 효과를 확인하지 않고 일반화

### 운영 규칙 및 QA
1. Product Identity: SKU/패키지 버전/승인 이미지와 권리 확인.
2. Reference Quality: 해상도, 선명도, 가림, 배경 복잡도, 조명 색편향 점검.
3. Angle Coverage: 필요한 각도만, 같은 버전에서 준비.
4. Model Input: 모델별 이미지 수·순서·형식 제한 확인.
5. Preview QA: 제품 실루엣, 색, 캡/라벨 위치, 반사, 형태 드리프트를 검수하고 실패한 참조만 교체.

### 8개 카테고리 매핑
- 광고·브랜드: 최우선 — 승인된 패키지 원본 확보
- 시네마틱: 조건부 — 화면의 핵심 소품 원본 확보
- 숏폼: 높음 — 첫 프레임 제품 인지성
- 제품·푸드: 최우선 — 실물 형태/포장 버전 유지
- 인물·캐릭터: 조건부 — 단일 인물·소품 참조 선명도
- 애니·판타지: 조건부 — 반복 등장하는 소품의 설정화
- 패션·뷰티: 최우선 — 화장품 용기·패션 아이템의 실물 일치
- 아트·실험: 선택 — 사실적 재현이 목표인 경우

### 변경 전후
이전: 레퍼런스 역할 지정 → 영상 생성 → 제품/브랜드 검수.
이후: **승인된 제품 참조 품질 검사** → 기존 레퍼런스 역할·예산 라우팅 → 영상 생성 → 제품/브랜드 검수.
