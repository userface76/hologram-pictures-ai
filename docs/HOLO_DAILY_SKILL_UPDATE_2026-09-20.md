## 신규 스킬 1 — Edit Memory Lock

**핵심 원리**
한 영상을 여러 번 수정할 때 매 수정 요청을 독립 생성으로 처리하지 않는다. 이전에 승인된 결과를 `edit memory`로 유지하고, 새 요청에서 변경 대상과 보존 대상을 분리한다. 얼굴·제품 형태·브랜드 요소·배경·이미 승인된 수정 영역은 보존 제약으로 유지하고, 이번 턴의 수정 영역만 다시 생성한다.

**적용 조건**
- 동일 영상에 2회 이상 순차 수정이 들어가는 경우
- 얼굴/의상/제품 패키지/로고/배경을 유지하면서 특정 동작·오브젝트·색·카메라만 수정할 때
- 장면 일부를 반복 보정하는 광고, 제품, 캐릭터, 패션 영상

**좋은 예시**
제품 광고에서 1차 수정으로 패키지 라벨을 확정한 뒤, 2차 수정에서는 손의 잡는 동작만 수정한다. 라벨·제품 비율·조명은 이전 승인 상태를 memory constraint로 잠근다.

**피해야 할 경우**
- 전체 미술 방향이나 캐릭터 자체를 교체하는 대규모 리디자인
- 이전 결과에 이미 구조적 오류가 있어 그대로 보존하면 오류가 누적되는 경우

**우선 적용 카테고리**
광고·브랜드, 제품·푸드, 인물·캐릭터, 패션·뷰티, 시네마틱, 애니·판타지

## 신규 스킬 2 — Timeline Patch Generation

**핵심 원리**
완성 영상의 일부가 어색할 때 전체 클립을 재생성하기보다 타임라인의 문제 구간을 먼저 지정하고 그 범위만 생성·교체한다. 수정 구간 앞뒤의 승인 프레임을 continuity anchors로 사용해 색, 인물, 제품, 공간과 동작의 연결을 유지한다. 목표는 `full regeneration`보다 `localized repair`를 우선하는 것이다.

**적용 조건**
- 1~수초 정도의 국소적 손/관절/접촉/제품 변형/전환 오류
- 전체 영상의 연출과 identity는 이미 승인된 상태
- 편집 타임라인 또는 구간 생성이 가능한 제작 환경

**좋은 예시**
10초 좀비 회피 장면에서 3.2–4.8초의 회피 반응만 어색하다면 전체 10초를 다시 만들지 않고 해당 범위를 지정한다. 직전의 주인공 자세와 직후의 달리기 자세를 연결 조건으로 두고 Reaction Chain 규칙을 적용해 중간 구간만 교체한다.

**피해야 할 경우**
- 문제 원인이 클립 전체의 잘못된 카메라 궤적이나 잘못된 캐릭터 디자인인 경우
- 앞뒤 프레임 자체가 서로 모순되어 국소 수정으로 연결할 수 없는 경우

**우선 적용 카테고리**
시네마틱, 숏폼, 광고·브랜드, 제품·푸드, 인물·캐릭터, 애니·판타지, 패션·뷰티

## 기존 구조와의 관계
- Multi-shot Asset Lock을 대체하지 않는다. Asset Lock은 샷 간 identity를 고정하고, Edit Memory Lock은 동일 결과물의 반복 수정 과정에서 승인 상태를 보존한다.
- Natural Motion QA / Reaction Chain에서 발견한 국소 오류의 실행 단계로 Timeline Patch Generation을 연결한다.
- Selective Repair 원칙을 실제 타임라인 단위 실행 규칙으로 구체화한다.
- Reference Motion Isolation과 충돌하지 않는다. 필요한 경우 patch 구간에만 motion reference를 적용한다.

## 변경 전 → 후
**전:** 생성 전에 reference 역할과 asset을 고정하고, 생성 후 자연스러움/상호작용 오류를 QA로 발견한다.

**후:** 발견된 오류를 수정할 때도 이전 승인 상태를 기억하고, 문제가 있는 시간 구간만 선택적으로 다시 생성하는 수정 계층을 추가한다. 따라서 불필요한 전체 재생성, identity drift, 제품/브랜드 변형과 토큰·생성 비용 증가를 줄이는 방향으로 HOLO 파이프라인을 확장한다.
