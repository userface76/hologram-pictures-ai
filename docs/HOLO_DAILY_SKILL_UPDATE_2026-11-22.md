# HOLO AI Daily Skill Update — 2026-11-22 (KST)

## 검토 범위와 채택
8개 카테고리(광고·브랜드, 시네마틱, 숏폼, 제품·푸드, 인물·캐릭터, 애니·판타지, 패션·뷰티, 아트·실험)를 기존 11월 11~21일 문서의 화면비, 컷 예산, 3앵커, 참조 일관성, 모델 라우팅 등과 비교했다. **신규 스킬 1개**를 채택했다. 2026-09-28 발표된 기능을 2026-11-22 재확인한 것으로, 오늘 출시된 기능은 아니다.

## 신규 스킬 — Draft-to-Final Reference-Locked Promotion Gate
- **원리:** Runway Dev의 Seedance 2.5는 `draft: true`로 480p 미리보기를 만들고, 성공한 작업의 `draftTaskId`만 전송해 1080p로 향상시킨다. 향상 단계는 미리보기의 프롬프트, 참조, 길이, 시드, 오디오 설정을 재사용한다. 공식 명세상 성공한 미리보기는 생성 후 7일 안에 향상할 수 있다. 480p 미리보기와 1080p 향상 각각 해당 요율로 과금된다.
- **조건:** Runway Dev의 Seedance 2.5 경로가 실제로 연결되고 draft 및 enhance를 지원할 때만 자동화 가능. HOLO의 MiniMax 직접 API에서는 동일 파라미터를 전송하지 않는다. 연결되지 않은 환경에서는 저비용 미리보기→사람 승인→최종 렌더링이라는 **운영 원칙**만 참고한다.
- **좋은 예:** 12초 9:16 세럼 광고에서 먼저 저해상도 초안으로 첫 2초 후킹, 손동작, 카메라 축, 한국어 멘트 분량을 검토한다. 승인된 초안의 ID와 참조 버전을 기록한 뒤 7일 이내 최종 향상. 최종본에서도 얼굴·제품 라벨·손·자막·발음은 별도 QA.
- **피해야 할 경우:** 미리보기에서 이미 얼굴/제품이 바뀌었는데 해상도 향상으로 해결된다고 가정; 최종본이 초안과 픽셀 단위로 동일하다고 보장; 7일 경과 작업을 재사용; 최종 렌더 전 비용/지원 경로를 확인하지 않음.
- **제안 기록 필드(미구현):** provider, model, draft_task_id, draft_created_at, promote_deadline, reference_version, prompt_version, draft_review, final_review, product_label_QA, identity_QA, Korean_audio_QA, approval.
- **중복 차이:** 11월 20일 모델 라우팅은 생성 전 모델 적합성 판단이고, 11월 11일 버전 고정은 재현성 관리이다. 이번 스킬은 **동일 작업의 초안 승인과 고해상도 향상 사이의 연속성·비용 통제**에 초점을 둔다.

## 변경 전후
- **전:** 프롬프트/참조 승인 → 바로 최종 생성 → QA.
- **후(지원 경로에서만):** 프롬프트/참조 승인 → 480p draft → 동작·정체성·제품·음성 초안 QA → 승인된 task ID로 7일 내 1080p 향상 → 최종 QA.
- **변경 범위:** 문서상 스킬 추가. HOLO MiniMax 엔진 코드, Runway 연결, 실제 영상 생성, 비용 측정, 배포는 수행하지 않음. 품질 향상 효과는 실측 전.
