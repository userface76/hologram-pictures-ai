# HOLO AI Daily Skill Update — 2026-11-19 (KST)

## 조사 및 중복 판정
8개 카테고리(광고·브랜드, 시네마틱, 숏폼, 제품·푸드, 인물·캐릭터, 애니·판타지, 패션·뷰티, 아트·실험)를 검토. 11월 9~18일 기록의 제품 교체, 레퍼런스 잠금, 컷별 시간 예산, 프롬프트 확장, 동작 전이, 색관리와 비교. **신규 채택 1개: 중간 키프레임 기반 단일 샷의 시간 앵커 검수**. 모델 출시일(2026-10-23)을 오늘 출시로 오인하지 않는다.

## 신규 스킬 — Three-Anchor Intra-Shot Transition & Identity Gate
- **핵심 원리:** 시작·중간·마지막 프레임을 지원하는 영상 생성 경로에서는 시작/종료만 고정하지 않고, 동작의 결정적 순간을 중간 프레임으로 지정해 한 샷 내부의 상태 전환을 설계한다. Runway Dev 공식 변경 기록(2026-10-23)은 Kling 4.0의 시작/선택적 중간·끝 프레임 입력과 3~30초, 720p/1080p 출력을 명시한다. 이 기능은 Runway Dev의 Kling 4.0 경로에 대한 근거이며 HOLO MiniMax H3 직접 API 지원을 뜻하지 않는다.
- **적용 조건:** 연속된 한 샷에서 명확한 3단계 상태가 필요하고, 해당 공급자/모델이 중간 키프레임을 지원하며, 각 앵커가 동일한 인물·제품·광원·카메라 축을 공유할 때. 3개 앵커 이미지의 권리·버전·화면비를 확인한다.
- **좋은 예:** 10초 세럼 광고의 0초 제품 정면, 5초 모델이 병을 집어 올린 상태, 10초 제품 라벨을 카메라에 보여주는 상태를 동일 인물·병 디자인·조명으로 제작. 0–5초와 5–10초의 손가락 수·제품 크기·라벨 방향·카메라 축을 따로 검사.
- **피해야 할 경우:** 컷 전환을 하나의 샷에 강제로 합치기, 앵커 사이에 다른 제품/인물/의상 사용, 물리적으로 불가능한 급격한 자세 변화, 라벨 텍스트 정확도를 생성 모델에만 맡기기, 지원하지 않는 MiniMax 요청에 middle-frame 파라미터를 임의로 추가하기.
- **QA 필드(문서 제안, 미구현):** provider, model_version, anchor_first_asset_id, anchor_middle_asset_id, anchor_last_asset_id, anchor_times, reference_rights, aspect_ratio, camera_axis_consistency, identity_consistency, product_geometry, label_legibility, hand_contact, transition_review, reviewer, verdict.
- **기존 스킬과 차이:** 11월 16일 Shot-Budgeted Multi-Cut Continuity는 **컷 간** 길이·연결을 관리한다. 이번 스킬은 **한 컷 내부**의 시작–중간–끝 상태를 앵커로 제어하고 구간별 일관성을 검사한다. 일반적인 첫/끝 프레임 잠금과도 구분되는 중간 상태 검증이다.

## 변경 전후
- **이전:** 승인 참조 → 시작/종료 또는 텍스트 동작 지시 → 생성 → 결과 QA.
- **이후(지원 공급자에서만 선택적):** 승인 참조 → 시작/중간/끝 상태와 시간 설계 → 앵커 간 동일성·동작 가능성 검사 → 지원 모델 생성 → 두 구간의 얼굴·손·제품·카메라 QA → 기존 납품 검사.
- **범위:** 일일 문서만 추가. HOLO 엔진 코드, MiniMax 어댑터, 실제 영상 A/B, Railway 배포는 변경하지 않음. 품질 향상은 실측 전.
