## 신규 스킬 1 — Model Capability & Cost Dry-Run Gate
**원리:** 영상 요청을 실제 생성하기 전에 모델별 입력 지원(이미지·비디오·오디오 레퍼런스, 화면비, 해상도, 길이, 오디오 생성)과 예상 비용을 검사한다. Runway Dev Model Router의 `POST /v1/generate/video`는 `dryRun: true`로 라우팅 결과와 추정 비용을 반환하며 생성 태스크·과금·영상 생성이 없다. `seed` 옵션도 문서에 있으나 동일 출력 보장은 모델·환경별로 별도 검증해야 한다.
**적용:** HOLO가 Runway Dev Model Router를 사용하는 경우 직접 사용 가능. MiniMax 직접 API만 사용한다면 동등한 자체 사전검증 로직을 설계할 수 있지만 Runway `dryRun` 파라미터를 그대로 보내서는 안 된다.
**좋은 예:** 9:16, 10초, 한국어 내레이션, 제품 이미지 1장이라는 요청을 모델 호환성/예상비용 확인 후 가능한 모델로 보내고, 음성 미지원이면 별도 TTS·합성 경로를 안내한다.
**피해야 할 경우:** dry run 비용을 실제 청구액과 동일하다고 확정하거나 품질을 보장한다고 주장하는 것. 지원되지 않는 API에 `dryRun`을 임의 전달하는 것. 자동 라우팅으로 승인된 얼굴·제품이 반드시 동일하게 재현된다고 간주하는 것.
**검수:** 실제 라우터 선택 모델, 입력 유효성, 추정/실제 비용, 실패율, 재시도율, 얼굴·제품 보존 점수를 기록. 모델 변경 시 명시적으로 알리고 승인 정책 준수.
**기존과 차이:** Reference Budget Router는 레퍼런스 입력 수/중복을 다루고, 오늘 스킬은 **모델 기능 호환성 및 과금 전 검증**을 다룬다.
**공식 근거:** https://docs.dev.runwayml.com/api/ ; https://docs.dev.runwayml.com/model-routers/generating/

## 신규 스킬 2 — Prompt Expansion Identity-Diff Lock
**원리:** 자동 프롬프트 보강은 카메라·조명·질감·움직임 등 구체성을 더하지만, 승인된 인물·제품·브랜드·한국어 대사를 바꾸면 안 된다. 원문과 확장문을 비교해 변경 가능한 연출 필드와 변경 불가 정체성 필드를 분리하고, 위반 시 확장문을 반려한다. Runway의 Enhance Prompt 가이드는 자동 확장이 카메라 각도, 조명, 질감, 모션, 분위기를 추가하며 사용자가 검토·수정할 것을 권장한다. 이 'diff lock'은 HOLO 자체 설계 규칙이며 Runway가 동일 기능을 제공한다는 주장이 아니다.
**적용:** HOLO 내부 LLM이 프롬프트를 확장하거나 카테고리별 스타일 프리셋을 덧붙이는 경우.
**좋은 예:** 원문 '승인된 흰색 세럼 병, 파란 로고, 한국어 대사: 피부에 촉촉함을 더하세요'를 확장할 때 '85mm 느낌의 클로즈업, 부드러운 측면 조명, 느린 돌리인'만 추가하고 제품 색/로고/대사 문자열은 원문 그대로 유지한다.
**피해야 할 경우:** 브랜드 로고를 텍스트 생성 모델이 다시 쓰게 하는 것, 한국어 대사를 의역해 음절 수와 의미를 바꾸는 것, 원문과 충돌하는 조명·제품 색·카메라 방향을 자동 추가하는 것, 의도적으로 실험적 변형을 요청한 경우에도 무조건 잠그는 것.
**검수:** 보호 필드 `product_id`, `package_version`, `brand_palette`, `character_identity`, `dialogue_exact`, `language`, `aspect_ratio`를 별도 보존; 프롬프트 변경 diff 및 승인 기록. 변경 허용 범위는 작업별 설정.
**기존과 차이:** Identity Anchor Plan은 샷 간 정체성 유지, 이번 스킬은 **프롬프트 자동 확장 단계의 변경 통제**.
**공식 근거:** https://help.runwayml.com/hc/en-us/articles/50012632982163-Enhancing-your-Prompts
