8개 카테고리(광고·브랜드, 시네마틱, 숏폼, 제품·푸드, 인물·캐릭터, 애니·판타지, 패션·뷰티, 아트·실험)를 검토했다. 11월 5~14일 기록의 참조 입력 충돌, 동작 명료화, UGC, 레이어 분리, 제품 교체 및 인물 일관성 스킬과 비교했다. 오늘은 기존 일반 참조 관리와 구별되는 **동작 전이 전 신체 비례·가림·프레이밍 적합성 검사** 1개를 채택한다.

## 신규 스킬 — Performance-to-Character Geometry Compatibility Gate
- **원리:** 인물/캐릭터 이미지에 퍼포먼스 영상의 동작을 옮길 때, 입력 영상의 관절 가시성·신체 비율·전신/상반신 프레이밍과 캐릭터 이미지의 대응 관계를 사전 검사한다. Kling 3.0 Motion Control의 공식 가이드는 동작 참조 영상과 캐릭터 이미지를 필수 입력으로 설명하며, 비율 불일치와 가려진 팔다리를 피하라고 안내한다.
- **적용 조건:** 권리 확보된 퍼포먼스 영상과 캐릭터 이미지가 있고, 지원 공급자에 동작 전이 기능이 있으며, 참조 영상의 인물 동작이 충분히 보이는 경우. 공급자별 길이·해상도·비용을 별도로 확인한다. HOLO MiniMax H3에 동일한 기능이 존재한다고 간주하지 않는다.
- **좋은 예:** 패션 10초 전신 워킹 영상의 발·무릎·팔이 모두 보이도록 촬영하고, 정면 전신 캐릭터 이미지의 팔다리 비율을 맞춘 후 전이한다. 결과에서 얼굴·의상·손·발·바닥 접지·발 미끄러짐을 프레임별 검수한다.
- **피해야 할 경우:** 상반신 사진에 격한 전신 춤을 전이, 팔·다리가 프레임 밖으로 잘린 참조 영상, 인물 뒤에 숨은 손, 크게 다른 신체 구조, 실제 인물의 동작/초상 이용 동의가 없는 경우.
- **HOLO 선택적 QA 필드:** performance_video_id, performance_rights, character_reference_id, character_rights, provider, model_version, body_visibility, limb_occlusion, framing_match, proportion_match, foot_contact_review, hand_geometry_review, face_identity_review, human_approval.
- **중복과의 차이:** 기존 다중 참조/인물 일관성 스킬은 무엇을 참조하고 동일성을 유지할지 관리한다. 이번 스킬은 **생성 전에 동작 전이의 기하학적 성립 가능성을 판단**하는 입력 적합성 게이트다.

## 변경 전후
- **변경 전:** 참조 이미지/영상 권리 확인 → 참조 역할 배정 → 생성 → 얼굴·손·동작 QA.
- **변경 후(선택적):** 권리 확인 → 동작 전이 필요성 판단 → **전신/상반신 프레이밍·관절 가시성·비율·가림 검사** → 공급자별 기능 확인 → 생성 → 기존 얼굴·손 QA + 발 접지/관절 왜곡 QA.
