## 신규 스킬 1 — Source-Preserving Video Edit Strength Ladder
**한국어:** 원본 보존 우선 영상 수정 강도 사다리

### 핵심 원리
이미 만들어진 영상을 처음부터 재생성하지 않고 **원본의 동작·표정·제품 정체성**을 보존할 정도를 명시한 영상 편집 경로로 수정한다. Luma Agents Ray 3.2 공식 API의 `type:"video_edit"`는 `video.edit.auto_controls:true`(권장 자동 제어) 또는 수동 `video.edit.strength` 및 `video.edit.controls`를 제공한다. 강도는 `adhere_1`~`adhere_3`(원본 밀착), `flex_1`~`flex_3`(절충), `reimagine_1`~`reimagine_3`(대폭 재해석)로 구분된다. 이들 값은 효과 보장이 아닌 모델의 편집 의도 설정이다.

### 적용 조건
- 완성된 클립에서 **배경 분위기, 조명, 소재 표현** 등만 바꾸고 동작은 유지해야 할 때.
- **Luma Agents Ray 3.2 연동이 실제로 존재하는 경우에만** 직접 API 제어 가능. MiniMax H3의 내장 기능으로 오인하지 않는다.
- 현재 공식 FAQ 기준 `video_edit` 소스 길이 최대 18초, 기본 소스 용량 200MB 이하(계정별 차이 가능). `source.url` 사용 시 `source.media_type:"video/mp4"` 등 영상 MIME 필수. 편집 출력 길이는 소스와 동일.
- 자동 제어(`auto_controls:true`)와 수동 `controls`를 동시에 전달하지 않는다.
- `video.start_frame` 단일 앵커와 `video.edit.keyframes` 다중 앵커는 상호 배타적. `image_ref`는 video_edit에 사용 불가.

### 좋은 예시
10초 세럼 광고의 인물 손동작·병 위치가 이미 만족스러울 때, 원본을 보존하고 배경을 따뜻한 스튜디오 분위기로 바꾸고자 한다. 먼저 원본 파일을 보관하고 `auto_controls:true`로 1회 미리보기한다. 정체성 손실이 나타나면 수동 `adhere` 계열을 별도 요청으로 비교한다. 병 실루엣/로고/얼굴/손의 변화가 없는 결과만 채택하고, 로고 글자는 기존 그래픽 합성 경로로 보호한다.

### 피해야 할 경우
- 이미 정확한 로고/제품/인물이 있는 영상을 불필요하게 강한 `reimagine`로 재해석.
- 원본을 덮어쓰거나 미리보기 없이 자동 게시.
- `video_reframe`(화면비 변경)과 `video_edit`(내용 재해석)을 같은 처리로 취급.
- MiniMax H3 요청에 Luma 전용 `strength` 필드를 무조건 추가.
- 자동 제어와 수동 제어를 동시에 전달해 API 오류를 유발.

### 검수와 검증
원본/편집본을 동시 비교: 인물 얼굴·손·제품 실루엣·로고, 동작/표정 타이밍, 카메라 진행 방향, 오디오 보존 여부, 비용·처리시간. 편집본이 원본보다 정체성 측면에서 나빠지면 사용하지 않는다. 실제 비용 절감 효과는 동일 프롬프트의 재생성과 비교 실험 전까지 주장하지 않는다.

### 기존 스킬과 구분
10/31 Identity-Safe Aspect Reframe Gate는 **화면비/주변 영역 확장**. 오늘의 스킬은 **이미 생성된 장면의 내용·스타일 수정에서 보존 강도와 입력 제약**을 다룬다.

## 신규 스킬 2 — Scene Color Reference Match Gate
**한국어:** 장면 간 색온도·노출·피부색 기준 프레임 검사

### 핵심 원리
연속되는 AI 영상의 조명·노출·화이트밸런스가 클립마다 달라질 수 있으므로 **기준 프레임(reference frame)** 을 지정하고 컷 전체의 색/명암을 비교한다. Adobe Premiere 공식 문서는 Comparison View, 참조 프레임, Apply Match, 얼굴 감지, Shadows/Midtones/Highlights 및 수동 보정을 소개한다. 2026-08-18 업데이트 문서 기준.

### 적용 조건
- 동일 장소/시간으로 이어지는 다중 클립, 같은 브랜드 제품의 여러 카메라 각도, 인물/뷰티 광고, 제품 패키지 색상 유지.
- 같은 조명 조건으로 보여야 하는 컷에만 적용. 의도적으로 다른 시간대·광원을 연출한 컷은 일괄 색상 매칭 대상이 아니다.
- HOLO에서 자체 구현한다면 우선 **비파괴적 편집/색보정**을 권장하며, 자동 색상 보정이 항상 올바른 색을 보장하는 것은 아니다.

### 좋은 예시
동일 세럼 광고의 10초 클립 3개를 연결한다. 승인된 제품·피부색이 가장 정확한 첫 번째 컷의 대표 프레임을 기준으로 삼고, 나머지 컷에서 중간톤·하이라이트·화이트밸런스·병 색상을 비교한다. 인물 컷은 피부색을 우선하고, 제품 컷은 실제 패키지 색상과 라벨 가독성을 우선한다. 자동 매칭 뒤 반드시 수동으로 확인한다.

### 피해야 할 경우
- 황혼 장면과 실내 야간 장면을 무조건 동일 밝기로 만드는 것.
- 얼굴 감지 결과만 신뢰해 제품 고유색을 바꾸는 것.
- 단일 프레임만 맞춘 뒤 클립 중간의 색 깜빡임을 확인하지 않는 것.
- 광원 변화/제품 색 변화가 의도인지 오류인지 구분하지 않는 것.

### 검수와 검증
각 클립의 시작·중간·끝 프레임을 비교하고 노출·하이라이트/그림자·색온도·피부색·제품 색·밴딩/플리커를 기록한다. 승인된 기준 프레임과 비교한 결과를 사람 검수로 최종 승인. 필요 시 웨이브폼/벡터스코프 사용. 자동 일치율 수치는 실험 전 제시하지 않는다.

### 기존 스킬과 구분
10/30 Last-Frame Bridge with Seam QA는 **클립 경계에서 구도/움직임 연속성**을 검사한다. 이번 스킬은 **전체 시퀀스의 노출·색상·피부/제품 톤**을 별도로 관리한다.

## 변경 전후 요약
- **변경 전:** 승인된 레퍼런스 → 모션/대사 검사 → 생성 → 오디오/클립 이음새 QA → 화면비 리프레임.
- **변경 후:** 기존 흐름 유지 + (지원 모델에서만) **기존 영상 수정 시 원본 보존 강도 선택·검수** + **다중 클립의 기준 프레임 색상 매칭·전체 타임라인 색상 QA**.
- **비중복:** 수정 강도 ≠ 화면비 리프레임. 색상/노출 연속성 ≠ 마지막 프레임의 위치·동작 연결.
- **검증 상태:** 공식 기능/편집 원리 확인, HOLO 런타임 구현/영상 생성/A-B 실험/배포 미실시. 비용 절감과 품질 향상은 실측 전 가설.
