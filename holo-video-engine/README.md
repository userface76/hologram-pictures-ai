# HOLO VIDEO ENGINE v0.1
Status: offline R&D; no GPU or paid API calls authorized.
## Technical boundaries
Studio: existing production UI and commercial providers, unchanged.
Skill Engine: model-neutral direction, camera, lighting, motion, continuity and QA; daily research stays in existing skill documentation.
HVE: self-hosted inference interface, model registry, workflow adapters, dataset provenance and evaluation. Initial candidate Wan 2.2 TI2V-5B; upstream weights are not HOLO-owned. ComfyUI is an initial execution adapter, not a foundation model.

A: CPU-only contracts, mock tests, model license and dataset manifest. No downloads of weights or deployment.
B: after explicit spending approval, GPU inference and five-second MP4 acceptance; then 15-second composition.
C: licensed training data and LoRA experiments; measure against unchanged baseline.
D: independent foundation model research, separate funding and feasibility gate.
## Cost policy
No GPU provisioning, paid API calls, paid storage creation, production deployment or paid CI overages. Use existing free allowances only; stop if quota cannot be verified. No automatic commercial fallback.
## Acceptance
Distinguish mock results from actual inference, measured cost and quality. Do not claim proprietary base weights. Preserve upstream license and dataset rights. Existing production branch unchanged.
