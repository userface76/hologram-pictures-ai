# Source Notes — One-line to Advanced Prompt Ladder

Status: SOURCE / CURATED NOTES
Source type: user-supplied HOLO training material
Runtime promotion: distilled into HOLO Director Runtime v1.7.2 and Skill Router

## Core pattern
The source describes a three-stage prompt ladder.

### Stage 1 — One-line prompt
Goal: say only the core idea. High creative latitude, low control.

Patterns:
- product/topic only
- topic + one visible moment
- style + subject + one action or one short line of dialogue

Operational takeaway:
- preserve brevity when the user's idea is intentionally simple
- one primary action is enough
- do not automatically turn every short idea into a technical shot list

## Stage 2 — Basic structured prompt
The source groups one scene into:
- scene description
- camera shot / angle
- mood
- actions
- dialogue
- sound

Operational takeaway:
- this is the balanced middle level for reliable generation
- translate mood into visible production cues when useful
- dialogue and sound support the scene rather than dominate it

## Stage 3 — Advanced camera and timing
The source demonstrates beat-by-beat short-video direction using:
- lens
- depth of field
- camera movement
- shot size / angle
- time ranges
- actions
- dialogue
- background sound
- lighting logic
- color palette
- emotional objective
- deliberate final/poster frame

Operational takeaway:
- use this level only when the user needs precise control or already supplies timed/camera detail
- timing beats must fit total duration
- each beat should have one dominant purpose
- camera and lens changes need a reason
- continuity and physical realism remain more important than technical density

## HOLO routing interpretation
- Level 1: one-line-creative-prompt + granularity-restraint
- Level 2: basic-structured-prompt + scene-camera-action-dialogue-sound
- Level 3: advanced-timing-choreography + lens-dof-progression + timed-sound-design + end-frame-hold

## A/B/C behavior
- A CONTROL may add one level of structure when reliability requires it.
- B IMPACT may add one level when stronger visual direction materially improves the shot.
- C USER BASED normally preserves the user's existing prompt level and only fills missing production language.

## Important restraint
More detail is not automatically better. HOLO should choose the minimum useful granularity for the task and model motion budget.
